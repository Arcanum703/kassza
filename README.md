# Kassza

Private receipt and bank-statement ledger powered by **Gemma 4**. Photograph a receipt, get a validated ledger row with the VAT split; import a bank CSV, get spending advice where every number is checked against your own data. Runs fully offline with Ollama, so your financial life never leaves your machine.

Work in progress — built at Hacktoberfest Hack Day Budapest, 31 Oct 2026.
